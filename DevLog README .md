# SwingingMechanic

Developed with Unreal Engine 5

Use W,A,S,D to move. Use SPACE to jump. Use F to lach onto swinging graple points.

This is my Project 2: DevLog.
    For this part off my project I was still working on the SpiderMan grapple mechanic. Some of the things that I said in my Postmortem that I wanted to add were a release mechanic with a character is launched forward and a fix to one of my previous bugs where the cycle starts over instead of going back and forth naturally like someone swinging. 
    I was able to complete both of my Must-Have goals from my postmortem. Unfortunately I couldn't figure out my stretch goal of making a string attached to the player and the grapple point but that doesn't mean I didn't do anything else for the project to make it better. Originally the level was a top down which I figured wasn't a great way to showcase the mechanic. So instead I made the level into a third world view of the character. Now the character was being tracked by a camera as it moved and the camera could be moved along the grapple poins as the character swung around.
    One of my bugs was from last project was understanding why the cycle for swinging started over from the beginning instead of moving back and forth, teleporting the character along with it.  This obviously does not feel natural for a game as it's not swinging it's more like teleporting.  I did eventually figure out how to fix this and make the swing feel natural.  one of the problems I had this project was getting the character to turn while swinging to adjust its position and direction.  instead of the character changing direction instead the grapple point completely reset to the center of the world and was clipping through one of the objects. I did not want the character and the grapple point to teleport so I had to fix this. In order to fix this I realized I had these actor position set instead of the rotation. By accidentally making it position instead of location it was using variables that I hadn't set yet and teleported it to the center of the world. By setting it to rotation now the grapple point wouldn't move it location, and instead rotate to the character.
